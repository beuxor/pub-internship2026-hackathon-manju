# シティゲッサー 要件定義書

## 1. プロダクト概要

世界の都市に関する統計・気候・名物などのヒントだけを頼りに、その都市の位置を世界地図上でクリックして当てるブラウザゲーム。Snowflake 上の Streamlit in Snowflake (SiS) としてデプロイする。

## 2. ゲームフロー

| フェーズ | 画面 | 内容 |
|---|---|---|
| **SETUP** | トップ画面 | ルール説明、設定、ゲーム開始ボタン |
| **GUESSING** | 出題画面 | ヒント表示 + 世界地図クリックで回答 |
| **RESULT** | 結果画面 | 正解位置・回答位置・距離・スコア表示 |
| **SUMMARY** | 最終結果画面 | 全ラウンドの成績一覧と地図上の俯瞰 |

## 3. 機能要件

### 3.1 設定機能（サイドバー）

- **ラウンド数**: 3 / 5 / 10 から選択（デフォルト: 5）
- **難易度**: すべて / やさしい(easy) / ふつう(normal) / むずかしい(hard)
- **乱数シード固定**: 同じ出題を再現可能にするオプション（0〜99999）
- **データ取得元切替**: 同梱JSON or Snowflakeテーブル（テーブル名指定可）
- **リセットボタン**: ゲーム状態を初期化してSETUPに戻る
- ゲーム進行中は設定変更不可（disabled）

### 3.2 都市データ

- **必須カラム**: name, country, lat, lon, population, gdp_per_capita, climate, avg_temp_c, annual_precip_mm, industries, specialties, landmark_hint, difficulty
- **データソース（優先順）**:
  1. Snowflake テーブル（`GEOGUESSER_CITIES`、設定で変更可）
  2. 同梱 `cities.json`（Snowflake接続失敗時に自動フォールバック）
- **バリデーション**: 必須列チェック、数値型変換、座標範囲チェック（-90〜90, -180〜180）、欠損行除外
- **難易度分類**: 各都市に easy / normal / hard のいずれかを付与

### 3.3 ヒントの段階開示（3段階）

| レベル | 開示内容 | 得点係数 |
|---|---|---|
| Lv1（初期） | 気候区分、年平均気温、年間降水量、人口規模帯 | ×1.00 |
| Lv2（追加1回） | 主要産業、経済水準（GDP帯） | ×0.85 |
| Lv3（追加2回） | 名物・名産、地形・ランドマーク | ×0.70 |

- 人口は正確な値ではなく帯表示（100万未満 / 100万〜500万 / ... / 2000万超）
- GDPも帯表示（5千ドル未満 / 5千〜1.5万 / ... / 6万ドル超）

### 3.4 地図・回答機能

- **ライブラリ**: Folium + streamlit-folium
- 世界地図（初期表示: 緯度20, 経度0, zoom 2）でクリックして回答地点を選択
- クリックするとピンが立ち、座標が表示される
- 「この地点で回答」ボタンで確定（ピン未設置時は disabled）

### 3.5 採点ロジック

- **満点**: 5,000点/ラウンド
- **距離計算**: Haversine 公式（地球半径 6,371.0088 km）
- **パーフェクト判定**: 正解から 25 km 以内 → 満点
- **減衰関数**: `5000 × exp(-distance / 1500)` で指数的に減点
- **ヒント補正**: 素点 × 得点係数（Lv1: ×1.00, Lv2: ×0.85, Lv3: ×0.70）

### 3.6 結果表示

- 正解の都市名・国名
- 誤差距離（km）、素点、獲得スコア、ヒント補正差分
- **評価ラベル**:
  - 4,500点以上: パーフェクト級
  - 3,000点以上: かなり近い
  - 1,500点以上: 惜しい
  - 500点以上: 大陸は合っている？
  - 500点未満: 地球のどこかではある
- 地図上に回答ピン（青）・正解ピン（赤）・破線を表示

### 3.7 最終結果画面

- 総合スコア / 最大可能スコア、平均誤差、最小・最大誤差
- 得点率のプログレスバー
- ラウンドごとの成績テーブル（都市名、国、誤差、ヒント段階、素点、獲得スコア、評価）
- Plotly の Scattergeo 地図で全ラウンドの回答・正解を俯瞰表示

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| **実行環境** | Snowflake Streamlit in Snowflake（コンテナランタイム PY3.11） |
| **コンピュートプール** | TRAINING_STREAMLIT_POOL |
| **ウェアハウス** | TEAM_E_WH |
| **DB/Schema** | TEAM_E_DB.DEVELOPMENT |
| **Python依存** | streamlit[snowflake], folium, streamlit-folium, plotly |
| **キャッシュ** | Snowflakeクエリは `ttl=600` でキャッシュ、JSONは無期限キャッシュ |
| **レイアウト** | wide レイアウト |
| **言語** | 日本語UI |

## 5. アーキテクチャ（ファイル構成）

```
geoguesser/
├── app.py          UI層（Streamlit画面遷移・描画）
├── game.py         ロジック層（距離計算・採点・出題抽選・ヒント開示）
├── data.py         データ層（JSON/Snowflakeからの読込・バリデーション）
└── cities.json     同梱の都市データ（約40都市、全世界）
```

- **app.py**: UI と画面遷移。`st.session_state` でフェーズ管理
- **game.py**: UI 非依存の純粋関数。テスト容易
- **data.py**: データソース抽象化。Snowflake 失敗時は JSON フォールバック
